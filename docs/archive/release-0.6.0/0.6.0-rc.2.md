## What changed since rc.1

The GPT review of `442220f` and an independent Opus review of the fixes, adjudicated by Opus:

- A paste happens only with the caret checked at the end of the draft, on every path, and right before ⌘V (review F01, reviewer #2).
- The target conversation is checked again right before writing, after downloads (F02).
- A file link is used only for the conversation page it was requested on (F03, reviewer #3).
- Returning to a recent conversation keeps the base its next reply merges onto (F04); a failed socket replay is dropped (reviewer #6).
- The clipboard is restored only if nothing else was copied meanwhile (F05).
- Read-back keeps indentation (F06).
- An app is remembered as paste-only only after a paste reached it. Before, one read-only moment marked an app for good; the owner's Accessibility runner had carried such an entry since R0.
- Add re-picks the message box only when the chosen one no longer exists (the owner's "composer not found" on the first Add after launch).
- Not taken: a request id carried end to end, persisting intermediate delivery states, and a separate preview of one Add's exact payload. F07 was a documentation fix.
