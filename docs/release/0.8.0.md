# Add to Claude 0.8.0 · technical beta

_Talk it through in chat. Finish it in your agent._

## What's new since 0.7.0

- **Updates arrive by themselves.** Once a day Add to Claude checks this project's update feed, downloads a new version in the background and installs it when you quit. While one downloads, and once it is ready, the panel's header says so; **Relaunch to Update** there installs it now. A scheduled check never opens a window. **Check for Updates…** is in the menu-bar icon's menu, and Settings → About has both switches and **Check Now**. Updates are [Sparkle](https://sparkle-project.org) 2.10.0, verified by the project's EdDSA key and the app's code signature.
- **Long replies no longer disturb the bar.** While ChatGPT writes, the bar keeps the last complete result and says "reply in progress, not included"; Add still works on what is finished. The bar has one fixed height, so the page above never reflows because the bar said something. A refetch that brings the same conversation changes nothing on screen.
- **Reopening the panel** after a while continues where it was: no blank page or flash, and a page macOS stopped in the background reloads when you open the panel, not while you type.
- **Choosing a window is enough.** You no longer need to click into the message box first: Add finds the window's box when it runs (the one you used last in the same conversation, the one with focus, or the window's only one), and refuses a terminal or code pane, or a box that changed.
- **Fixed:** in Chinese prose, text after a bare `sandbox:` path became part of a file's name in the content checks, and a placeholder path such as `sandbox:/mnt/data/...` was listed as a file.

## Install

Apple silicon, macOS 14 or later.

1. Download `add-to-claude-0.8.0.zip` below and check its SHA-256: `TBD`.
2. Unzip and move **Add to Claude** to Applications, then open it. macOS refuses the first time: System Settings → Privacy & Security → **Open Anyway**.
3. Sign in to ChatGPT in the panel, choose **Allow…** for Accessibility, choose a window in the bar, and **Add**.

## Updating from 0.7.0 or earlier

Quit Add to Claude, replace **Add to Claude** in Applications with the new one, and open it. This is the last time: from 0.8.0 on, updates install themselves. Settings, sign-in and the Accessibility grant carry over.

## Known limits

As in [0.7.0](0.7.0.md#known-limits). For updates:

- Each check tells GitHub your IP address and the app's and Sparkle's versions. Turn checks off in Settings → About.
- Once an update is downloaded, checks pause until it is installed: a newer release is found after the next launch.
- Releases are signed with the author's own certificate and are not notarized. Whoever holds the project's update key can ship code to installed copies; see the [threat model](../threat-model.md#accepted-risks).
