# Add to Claude 0.6.0 · private technical beta

_Talk it through in chat. Finish it in your agent._

A menu-bar ChatGPT panel that adds the conversation you have open to the end of a draft in Claude, Claude Code or another app's message box. It never sends, never presses Enter, and keeps no transcript.

## What's new since 0.5.0

- **Add only what is new.** Add remembers which turns went into which Claude conversation (ids, positions and hashes, never message text), offers **New · N** next time, and marks turns that changed since. **Choose turns…** picks any subset; the last batch is marked so a manual add is easy to review. Settings → History turns it off or clears it.
- **Files come along.** Generated and uploaded files are downloaded on Add into `~/Downloads/Add to Claude/<conversation>/`, and each file line in the text carries its local path and SHA-256.
- **Cleaner text.** ChatGPT's layout markup (cards, entities, citations) reads as plain Markdown; repeated content checks are listed once.
- **Safer writing.** The caret is checked at the end of the draft before every write, the target conversation is checked again after downloads, the clipboard is restored only if you have not copied since, and a reply still streaming keeps Add off until it ends.
- **Settings** for login, panel behaviour, a global shortcut, files, history, web cache, diagnostics export (no message text) and access. It opens in the panel's place and closing it goes back.
- **New icons**: a calm arc landing at the end of a line, in the menu bar and in the Dock.
- **Keeps its permission across updates**: builds are signed with one stable certificate.

## Install

Apple silicon, macOS 14 or later.

1. Download `add-to-claude-0.6.0.zip` below and check its SHA-256: `<filled in at publish>`.
2. Unzip and move **Add to Claude** to Applications, then open it. macOS refuses the first time: System Settings → Privacy & Security → **Open Anyway**.
3. Sign in to ChatGPT in the panel, choose **Allow…** for Accessibility, click once into the message box you want, choose its window in the bar, and **Add**.

## Known limits

- Not notarized and not Developer ID signed: this is a beta for trusted machines.
- ChatGPT is the only source. Claude Code sessions in Claude for Mac are recognised by their conversation id; other targets, including Claude chats until their id is seen, are recognised by window, and Add offers everything again after you switch conversations there.
- Claude's editor reformats pasted Markdown, so an add there can end "Could not confirm" with **It's There / It's Not** to settle it.
- Reading is passive: open the conversation again to pick up a reply that finished while the panel was closed.
