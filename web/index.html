    ONE-TIME SETUP

    Connect your current chat

    1. In Chrome, open chrome://extensions and enable Developer mode.
    2. Choose Load unpacked and select the included chrome-extension folder (or dist/extension in a source build).
    3. Pin gpt-handoff. Open a ChatGPT conversation and choose Use this conversation, then Open in local desk.

    The extension reads this tab when you ask. Review missing turns here; an export can preserve content the page has not loaded.
